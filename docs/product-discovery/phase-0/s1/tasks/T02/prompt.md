Bug report: `parseCSV` breaks rows whose quoted fields contain commas or escaped quotes. For example `parseCSV('id,name\n1,"Smith, Jane"\n2,"He said ""hi"""\n')` should return `[["id","name"],["1","Smith, Jane"],["2","He said \"hi\""]]`. Fix the parser (RFC 4180 style quoting within a line is enough; newlines inside quotes are out of scope). Keep existing behaviour for simple rows.
