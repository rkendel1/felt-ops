Feature: `renderTable(rows, { align })`. `align` maps column names to `"left" | "right" | "center"` and sets the Markdown divider for that column (`:---`, `---:`, `:---:`). When `align` is not given, columns whose values are all numbers are right-aligned (`---:`) and other columns keep `---`. Example: `renderTable([{ item: "Pen", qty: 2 }])` → `"| item | qty |\n| --- | ---: |\n| Pen | 2 |"`. Update existing tests if their expectation changes because of this new default, and explain why in your final message.
